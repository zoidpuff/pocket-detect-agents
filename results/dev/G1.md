# Gate G1 — BURROW candidate recall (dev, interim data)

Date: 2026-10-26. Owner: method developer (BURROW). Status: **G1 passed on interim dev data**
(90.97 % recall at ≤ 40 pockets/protein; target ≥ 88 % at ≤ 40). To be re-measured on the
BioLiP2 dev set (Track A) when it is final.

## Data
Interim development data (Track A's BioLiP2 train/dev sets were a 20-entry smoke run at the time):
CHEN11 (251 structures) + JOINED (537 = ASTEX 78, B210 176, BU48 93, DT198 190) from
`data/raw/p2rank_datasets` — P2Rank's own training/validation sets, **not** project test sets.
Labels: harness `p2rank` ligand rules (ions are "small" → not targets). 683 structures with ≥ 1
relevant ligand, 974 ligands (CHEN11 407, JOINED 567). Manifests: `results/dev/manifests/`
(`scripts/burrow_dev_manifests.py`). 436 files were sanitized (copies in
`results/dev/structures_sanitized/`, git-ignored): blank chain ids → unused letter, columns 73–80
blanked (old-format seq numbers that gemmi rejects). The same files go to every method.

## Definition
A ligand is recalled iff at least one candidate pocket (before ranking) has, *for the same pocket
centre*, DCC ≤ 12 Å (to the ligand centroid) **and** DCA ≤ 4 Å (to any ligand heavy atom).
#pockets/protein = candidates after NMS (centre < 5 Å or residue Jaccard ≥ 0.75), capped at 40 by
geometric strength Σ vol·buriedness. Script: `scripts/burrow_g1.py`; per-ligand table
`results/dev/G1/g1_ligands.csv`, summary `results/dev/G1/g1_summary.csv`.

## Candidate generator (geometry only, no learning)
1 Å grid points with |x − a| ≥ r_vdW + 1.0 Å for all atoms and nearest atom ≤ 6 Å; LIGSITE PSP
prefilter (7 directions, 8 Å; keep PSP ≥ 2 + a 2 Å sub-lattice of the rest, volume weight 8);
capped metal candidates; 60-ray dual-grid buriedness. Point value b = mean(blocked@10,16,24 Å).
Components (single linkage 2.05 Å) at thresholds b ≥ 0.40/0.55/0.70/0.85; components longer than
20 Å split by weighted k-means (12 Å pieces); every component with extent > 10 Å also contributes
k-means sub-pockets of ~6 Å (multi-scale candidates); min volume 10 Å³.

Notes
* The variant grid (7 variants) was explored on all 974 ligands; the chosen variant is also the
  best on each subset separately, so selection optimism is small but not zero.
* Main failure mode without sub-pockets: the ligand sits in a pocket that is found but is larger
  than the ligand, so the centroid is 4–7 Å from every ligand atom (DCC ≤ 12 but DCA > 4).
  Multi-scale k-means sub-pockets fixed most of these (+6.9 points).
* fpocket/P2Rank output fewer pockets; at equal pocket budget their recall would be lower or equal
  (P2Rank does not output more). "fpocket candidates + BURROW ranker" remains a mandatory ablation.
* The learned pipeline adds score-based candidates (point-score thresholds .15/.30/.50) to this
  set before ranking, so its pre-ranking pool is a superset.

## Addendum (2026-10-26 19:30) — G1 re-measured on the audited BioLiP2 dev set (579 chains, 1,221 sites incl. 416 ion-only)
`scripts/burrow_g1_biolip.py`, tables `results/dev/biolip/G1_biolip_{default,accurate}.csv`. Same
definition (one candidate centre with DCC ≤ 12 Å to the site centre AND DCA ≤ 4 Å to a site ligand
atom; geometry-only candidates, LIGYSIS-redundancy NMS 5 Å / J 0.75, ≤ 40 per chain).

| candidate set (default feature design) | recall | candidates/chain |
|---|---|---|
| BURROW geometric, ≤ 40 (ordered by Σ vol·b; buried-volume order: 58.9) | **58.6** | 40 |
| BURROW geometric, NMS, no cap | 79.8 | 177 |
| BURROW geometric pool, no NMS, no cap | 87.9 | 650 |
| BURROW full pre-ranking pool (geometric + point-score candidates; accurate s0 model) | 93.6 (non-ion 97.3, ion-only 86.5) | 387 |
| fpocket 4.2.3, all pockets | 47.3 | 20.7 |
| P2Rank 2.5.1, all pockets | 38.8 | 4.2 |

**G1 as defined is NOT met on the BioLiP2 dev set** (58.6 % at ≤ 40 vs the 88 % target; the
accurate feature design gives 54.5 %). On single representative chains with pooled LIGYSIS-style
sites (incl. ion sites, where the centre must be within 4 Å of one atom) a 40-candidate geometric
budget is too small; the interim-data pass (91 %) does not transfer. The DESIGN fallback
("fpocket candidates + our ranker") is not better: fpocket's own candidates recall 47.3 %, and the
mandatory ablation (PHASE2.md) shows fpocket candidates + BURROW ranker lose 16 pt DCA4 top-N+2 and
13 pt P1K against BURROW's own candidates at equal LIGYSIS top-N+2. Decision proposed to the PI:
keep BURROW candidates (gate miss documented; candidate recall is enforced by the learned
pipeline, whose pre-ranking pool reaches 93.6 %).
