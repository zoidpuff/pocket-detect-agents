# CryptoBench train-fold apo-dev diagnostic (DEV ONLY)

Generated by `scripts/run_apo_dev.py`. GT: `data/processed/gt/cryptobench_trainfolds/` (README there). Folds 0-3 of the CryptoBench train split (885 apo structures;
never the test split). Recall = site hit by a pocket of rank <= N+2 (N = #sites of the structure), closest-pocket protocol (site_eval); DCC12 = centre within 12 A of the
site-residue CA centroid; DCA4 = pocket with minimum distance-to-ligand-atom <= 4 A, ligand = holo ligand transferred into the apo frame (CA Kabsch on pocket residues).
CIs: bootstrap over UniProt units (no sequence-cluster map exists for train folds); paired differences use the same resamples. Models: BURROW default presets, seed-0 models
from results/dev/biolip/models (trained on BioLiP2 with the CryptoBench-excluded train set), P2Rank 2.5.1 default, fpocket 4.2.3 (+PRANK 2.5.1).

## Notes / caveats
- N (for top-N+2) is per table: cryptic table N = #cryptic sites of the structure; non-cryptic table N = #auxiliary non-cryptic pockets (separate evaluation, no pooled N); holo table N = #sites of the holo entry (950 sites vs 1,091 apo sites: the holo table uses only the main holo entry of each apo, so the apo->holo "drop" compares slightly different site sets and is descriptive).
- DCA4 uses transferred ligands (CA Kabsch of holo onto apo pocket residues; 1,047/1,091 sites have >=1 transferred ligand, transfers with fit RMSD > 4 A dropped); the non-cryptic table has no ligand atoms.
- Train folds contain apos whose holo entries use different apo chains: input = union of chains (the test split obeys CryptoBench's strict "the_most_chains" rule). Insertion-coded residues occur in train folds: `src/pocketdetect/importers/cryptobench.py` now parses `B_60A` (test GT re-built bit-identical).
- Resampling units are UniProt ids (no sequence-cluster map for train folds). BURROW seed-0 default models were trained with CryptoBench excluded; P2Rank/fpocket+PRANK are the project's baseline wrappers (P2Rank on apo inputs of train-fold structures: P2Rank's training set (CHEN11) may overlap by protein family).
- Raw: `baselines/outputs/apo_dev/` (git-ignored); summary table: `results/dev_apo/summary_long.csv`, `paired_comparisons.csv`.
